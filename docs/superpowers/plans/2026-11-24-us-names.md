# US Names Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every name Unique Names suggests or uses is a real US name ranked 101 to 2,000 (widened to 5,000 for
letters that are short of names), so posts read as made for the US, Canada, the UK and Australia. A one-time Names
page check skips the library's names that don't fit.

**Architecture:**
- The official US SSA baby-name data is built into a committed JSON file (`packs/unique-names/us-names.json`) by a
  script.
- A server-only module (`lib/names/us-list.ts`) answers "is this a US name for this gender and letter".
- The check is applied at the server call sites that save or return AI name suggestions; the shared
  `lib/ai/suggest-filter.ts` is not changed, because client components import it.
- The suggestion and Autopilot-judge prompts are rewritten for the new audience.
- A Names page button previews, then applies, the library cleanup. The page shows each name's US rank, computed on
  render.

**Tech Stack:** Next.js 16 (App Router, server actions), Supabase, Gemini/Claude via `lib/ai/provider.ts`, vitest,
jszip (already used by `scripts/lib/ssa.ts`), tsx for scripts.

**Spec:** `docs/superpowers/specs/2026-11-24-us-names-design.md` (approved; it governs). Branch: `feature/us-names`.

## Global Constraints

- A single name is a "US name" when its best rank over the last 3 SSA years for that gender is **101 to 2,000**.
- For a letter where that gender's list has fewer than **25** names ranked 101–2,000, the upper bound for that letter
  and gender is **5,000**.
- Two-word names (initials posts): both words are on that gender's list within the top **5,000**, and the first word
  is not in the top **100**.
- Lookups ignore case and accents ("Zoë" = "zoe").
- The skip note is exactly **`Not a US name`** (stored in `names.autopilot_note`).
- An available name that already carries that note was restored by the owner and is never skipped again.
- Only `available` names are touched. Used and already-skipped names are left alone. Nothing is deleted.
- Names the owner adds by hand (`addNamesAction`, bulk paste) are never checked.
- The whole feature is behind the pack flag `suggest.usNames === true`, set only by Unique Names. Name Nest is
  unchanged (`packs/name-nest/*` untouched).
- The US list JSON must never reach the browser: `lib/names/us-list.ts` starts with `import "server-only"`, and no
  client component imports it.
- No database migration. The cleanup is batched updates (chunks of 200 ids), never one request per name.
- Not changed: captions, post times, the babies' looks, posts already made or scheduled, the front card and the
  3-best ranking.
- AGENTS.md: this Next.js has breaking changes; never export plain helpers from a `"use server"` file. Shared logic
  goes in `server-only` modules.
- On this Windows PC vitest only starts under **PowerShell**: `npx vitest run <files>`, `npm test`,
  `npx tsc --noEmit`, `npm run lint`. Git from Git Bash is fine.
- The owner has unrelated uncommitted edits (`.gitignore`, `eslint.config.mjs`, `tsconfig.json`, `reels3d/` and
  untracked files). `git add` only the explicit paths a task lists. Never `git add -A`, `git add .` or
  `git commit -a`.
- Every commit message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

/** The latest `count` yobYYYY.txt files in the zip, newest first: [{ year, text }]. */
export async function recentYears(zipBytes: ArrayBuffer | Uint8Array, count = 3): Promise<{ year: number; text: string }[]> {
  const zip = await JSZip.loadAsync(zipBytes);
  const years = Object.keys(zip.files).map((f) => ({ f, m: /^yob(\d{4})\.txt$/i.exec(f.split("/").pop() ?? "") }))
    .filter((x) => x.m).map((x) => ({ year: Number(x.m![1]), f: x.f })).sort((a, b) => b.year - a.year).slice(0, count);
  if (!years.length) throw new Error("names.zip has no yobYYYY.txt files");
  return Promise.all(years.map(async (y) => ({ year: y.year, text: await zip.file(y.f)!.async("string") })));
}

```ts
import "server-only";
import data from "@/packs/unique-names/us-names.json";
import { activePack } from "@/packs";
import type { Gender, NameStyle } from "@/lib/db/types";

/** The US list (official SSA data, best rank over the last 3 years; spec 2026-11-24): "unique but known" names. */
export const US_MIN_RANK = 101;
export const US_MAX_RANK = 2000;
export const US_WIDE_MAX_RANK = 5000;
export const US_LETTER_MIN = 25;
export const US_NOTE = "Not a US name";

export interface UsNamesData { years: number[]; girl: Record<string, number>; boy: Record<string, number> }

/** "Zoë " → "zoe": lowercase, no accents, trimmed. */
export const usKey = (name: string) => name.normalize("NFD").replace(/\p{M}/gu, "").trim().toLowerCase();

export function makeUsList(d: UsNamesData) {
  const inRange = new Map<string, number>(); // "girl|v" → names ranked 101..2000
  for (const g of ["girl", "boy"] as const) {
    for (const [k, r] of Object.entries(d[g])) {
      if (r >= US_MIN_RANK && r <= US_MAX_RANK) inRange.set(`${g}|${k[0]}`, (inRange.get(`${g}|${k[0]}`) ?? 0) + 1);
    }
  }
  const rank = (name: string, gender: Gender): number | null => d[gender][usKey(name)] ?? null;
  const maxRankFor = (letter: string, gender: Gender): number =>
    (inRange.get(`${gender}|${usKey(letter).charAt(0)}`) ?? 0) < US_LETTER_MIN ? US_WIDE_MAX_RANK : US_MAX_RANK;
  const isUsName = (name: string, gender: Gender, letter?: string | null): boolean => {
    const r = rank(name, gender);
    return r !== null && r >= US_MIN_RANK && r <= maxRankFor(letter ?? usKey(name).charAt(0), gender);
  };
  const isUsTwoWord = (name: string, gender: Gender): boolean => {
    const w = name.trim().split(/\s+/);
    if (w.length !== 2) return false;
    const a = rank(w[0], gender), b = rank(w[1], gender);
    return a !== null && b !== null && a >= US_MIN_RANK && a <= US_WIDE_MAX_RANK && b <= US_WIDE_MAX_RANK;
  };
  return { rank, maxRankFor, isUsName, isUsTwoWord, latestYear: Math.max(...d.years) };
}

export const US_LIST = makeUsList(data as UsNamesData);

/** True on a pack that aims its names at the US, Canada, the UK and Australia (Unique Names). */
export const usGateOn = () => activePack().suggest.usNames === true;

/** Keep only US names (when the pack asks for it); `dropped` counts the rest. */
export function keepUsNames<T extends { name: string }>(list: T[], gender: Gender, o: { style: NameStyle; letter?: string | null }): { kept: T[]; dropped: number } {
  if (!usGateOn()) return { kept: list, dropped: 0 };
  const ok = (n: T) => (o.style === "two-word" ? US_LIST.isUsTwoWord(n.name, gender) : US_LIST.isUsName(n.name, gender, o.letter));
  const kept = list.filter(ok);
  return { kept, dropped: list.length - kept.length };
}
```
